TUS ESCUCHAS CUENTAN

Trae tu historial.

Importa el historial JSON de Spotify o una lista CSV / JSON. Selecciona juntos todos los archivos del historial para calcular las escuchas y evitar eventos repetidos.

Se cuentan eventos de al menos 30 segundos. Reimportar conserva el mayor conteo por canción; no suma dos veces el mismo historial.

Formatos, alcance y privacidad

CSV: columnas title,artist,album,source,liked,plays,url . JSON: lista con esos mismos campos. Solo title es obligatorio. source acepta spotify, youtube o import. liked acepta true o false.

También se admite el historial Spotify extendido (master_metadata_track_name, master_metadata_album_artist_name, ts, ms_played) y el básico (trackName, artistName, endTime, msPlayed). No se interpreta el historial Google Takeout en esta versión.

La captura solo lee filas cargadas y no observa tu reproducción en segundo plano. Los Me gusta se detectan por la lista oficial, no por estar en cualquier playlist. No se obtiene un historial completo desde la página. Los selectores pueden necesitar ajustes si las plataformas cambian.

No se piden contraseñas, cookies ni claves API. No hay telemetría ni servidor. La extensión guarda títulos, artistas, rutas relativas y tus decisiones en este perfil de Chrome.
